# Карьерный навигатор нового поколения

**Навигация между образованием и рынком труда через практику с применением ИИ-аналитики для профориентации.**

Проект разрабатывается в рамках кейс-чемпионата **«Лига решений»** при поддержке Правительства Санкт-Петербурга и Корпоративного университета Санкт-Петербурга (КОРПУС), на базе СПб ГБПОУ «Академия инженерных технологий и управления» (АИТУ).

---

## О проекте

Сейчас профориентационная работа в АИТУ реализуется через разрозненные форматы: экскурсии школьников в колледж, дни открытых дверей, мастер-классы и профпробы в рамках федеральных проектов «Билет в будущее» и «Профессионалитет», участие в городских мероприятиях, взаимодействие с работодателями-партнёрами. Каждый формат работает сам по себе — без единой сквозной модели, персонализации и цифрового профиля школьника.

Задача проекта — спроектировать **логику работы Карьерного навигатора нового поколения**: единой цифрово-практической системы профориентации, которая ведёт пользователя от диагностики интересов до трудоустройства, персонализируя каждый шаг с помощью ИИ-аналитики.

Итог работы — логическая модель (блок-схемы + сценарии ИИ-алгоритма), которая ляжет в основу технического задания для разработчиков и дизайнеров на следующем этапе. Проект развивается поэтапно, в рамках серии Проектных школ подготовки к кейс-чемпионату.

## Миссия

> Сформировать у молодёжи осознанный профессиональный выбор через практический опыт, цифровое сопровождение и персонализированную навигацию между системой образования и рынком труда Санкт-Петербурга.

## Центральная модель

```
Диагностика → Погружение → Маршрут → Осознанный выбор образования → Трудоустройство
```

Каждый этап фиксируется в цифровом профиле пользователя и используется ИИ для персонализации следующего шага.

## Какую проблему решает навигатор

- Фрагментарность профориентации — нет единой сквозной модели маршрута.
- Слабая персонализация — одинаковые мероприятия для разных школьников.
- Отсутствие единого цифрового профиля и цифрового инструмента построения карьерной траектории.
- Отсутствие системной аналитики интересов и склонностей обучающихся.
- Разрыв в траектории «школа → СПО/ВО → рынок труда», ограниченная практико-ориентированная навигация по профпробам и работодателям.
- Недостаточная вовлечённость работодателей в раннюю профориентацию.
- Сложность отслеживания эффективности мероприятий и дальнейшего карьерного пути выпускников.

## Целевая аудитория

| Группа | Ключевая потребность |
|---|---|
| Школьники 13–18 лет | Понятный персонализированный маршрут, практика «попробовать профессию» |
| Родители школьников | Структурированная картина карьерных перспектив ребёнка |
| Педагоги и профориентаторы школ | Цифровые инструменты диагностики и готовые сценарии маршрутов |
| Образовательные учреждения СПО/ВО | Осознанные абитуриенты, качественное профилирование поступающих |
| Работодатели и Молодёжный кадровый центр СПб | Раннее выявление и сопровождение кадрового потенциала |

## Ключевые инсайты

- Школьники часто выбирают профессию, не понимая её реального содержания.
- «Попробовать профессию» ценнее, чем просто узнать о ней.
- Пользователю нужен персональный маршрут, а не список профессий.
- Доверие формируется через практику, а не через презентации.
- Профориентация эффективнее всего при сопровождении на всех этапах: диагностика → практика → образование → трудоустройство.

## Что мы разрабатываем (итоговый продукт)

Минимальная рабочая версия Карьерного навигатора, включающая:

- логическую блок-схему работы навигатора;
- сценарии работы ИИ-алгоритма персональных карьерных рекомендаций (как ИИ рекомендует маршрут по итогам диагностики и профпроб);
- пробная версия системы
