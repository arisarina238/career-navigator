# Career Navigator — AI Backend

Backend AI-модуля проекта «Карьерный Навигатор».

AI-модуль отвечает за работу ИИ-ассистента, который общается с пользователем,
учитывает историю диалога и текущий сценарий прохождения карьерной навигации.

На текущем этапе AI работает локально через Ollama и модель Qwen3 8B.

В дальнейшем планируется перенести AI на общую серверную инфраструктуру,
чтобы разработчикам и пользователям не требовалось запускать Ollama
на своих компьютерах.


# 1. Архитектура

На текущем этапе система работает следующим образом:

React Frontend
       |
       | HTTP POST
       v
FastAPI Backend
       |
       | HTTP
       v
Ollama
       |
       v
Qwen3 8B


Frontend не обращается к Qwen напрямую.

Все запросы к AI проходят через FastAPI.

Это позволяет в дальнейшем:

- изменить модель без изменения frontend;
- изменить Ollama на другой AI-сервис;
- добавить авторизацию;
- подключить базу данных;
- хранить историю диалогов;
- добавлять рекомендации;
- изменять сценарии общения.


# 2. Что необходимо установить

Для работы backend необходимо установить:

1. Python 3.12
2. Ollama
3. Модель Qwen3 8B


# 3. Python

Для backend используется Python 3.12.

# 4. Настройка и установка зависимостей

Установка виртуального окружения:
    py -3.12 -m venv venv

Активация виртуального окружения:
    .\venv\Scripts\Activate.ps1

Установка Python-зависимостей:
    python -m pip install --upgrade pip
    pip install -r requirements.txt

Установка модели Qwen3:
    ollama pull qwen3:8b
    ollama list (проверка)

Проверка Qwen отдельно от проекта:
    ollama run qwen3:8b
    Написать: Привет (должен быть ответ выдан)
    Для выхода: /bye

Запуск FastAPI:

Перед запуском:
    перейти в backend;
    активировать venv;
    убедиться, что Ollama установлен и работает.

Активировать окружение:
    .\venv\Scripts\Activate.ps1

Запустить FastAPI:
    uvicorn app.main:app --reload

Backend будет доступен по адресу:
    http://localhost:8000

Swagger:
    http://localhost:8000/docs

Файл .env:
    OLLAMA_URL=http://localhost:11434
    AI_MODEL=qwen3:8b
